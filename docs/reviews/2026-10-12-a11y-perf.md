# Accessibility & performance: Nexa

## Accessibility
- axe-core (WCAG 2.0/2.1/2.2 A+AA + best-practice) on all 8 routes × 3 viewports: **0 serious/critical**.
- Keyboard: visible focus on every interactive element (automated tab walk); ARIA tabs with arrow/Home/End;
  native `<dialog>` (focus trap, Esc); ⌘K combobox with `aria-activedescendant`; skip links.
- Status never by color alone (text badges); charts have text summaries plus an optional data table.
- Contrast: filled buttons use `brand-strong` (5.2:1) and `violet-strong` (6.1:1); tertiary text `#8190A8` (5.8:1).
- Reduced motion: final states shown, no infinite animations (automated check).

Fixed during QA: a scrollable activity list that couldn't be reached by keyboard; inputs that suppressed the
focus outline; `role="tabpanel"` on `<ul>` breaking list semantics; a button name with a stray space.

Not done here: a manual VoiceOver pass by a human tester (recommended before any real launch).
