# Visual review: Nexa

Method: per-section and viewport screenshots (desktop 1440, tablet 820, mobile 390) reviewed by eye,
plus hands-on inspection of the dev build in Chrome (console clean, tour click-through).

| Criterion | Score | Notes |
|---|---|---|
| Hierarchy & typography | 5/5 | Two-line hero headline at ≥640px; consistent display/body scale |
| Color & brand consistency | 5/5 | Tokens only; one accent per section; violet/cyan only as light |
| Layout & spacing | 4/5 | Even rhythm; the mobile hero preview is tall but intentional |
| Interaction clarity | 5/5 | Every control works; simulated actions labeled |
| Responsiveness | 5/5 | No overflow at 390/820/1440 (automated + visual) |
| Polish / detail | 5/5 | Grain, hairlines, fold-shaded logomark, settled motion |

## Issues found and fixed (refinement pass)
1. Hero headline broke onto 3 lines → widened measure, explicit break at ≥640px.
2. Atmospheric glow behind the hero preview was clipped by the animated layer → moved the light out of the transformed element.
3. Reduced-motion users saw dimmed run steps (animation delays still applied) → `animation-delay: 0s` in the reduced-motion rule.
4. Chart axis labels collided ("Oct 11"/"Oct 12") and the y-scale wasted ~40% of the height → even-step labels, data-fitted scale.
5. Project avatars overlapped their initials → smaller overlap, larger avatars.
6. Project progress ring disagreed with the card (task ratio vs. project progress) → single source of truth.
7. Board status selects were visually heavy → compact, quieter styling.
8. Mobile top bar showed two "New task" buttons (base `inline-flex` overrode `hidden`) → wrapper element.
9. Mobile filters truncated, Board/List switch stretched → 2-column filter grid, content-width tabs, list view by default on phones.
10. Integrations felt static for a "connected" brand → hairline rails through the hub with a slow light pulse.
11. Guided tour card let dense content bleed through its glass (found in Chrome) → near-opaque surface.
12. "Most popular" pricing badge implied real data → "Recommended".
