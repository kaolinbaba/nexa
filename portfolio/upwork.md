# Upwork portfolio entry: Nexa

## Project title
Nexa: Premium AI SaaS Brand, Landing Page & Interactive Dashboard (Concept)

## Your role
Brand & UI/UX designer · Frontend developer

## Project description
Nexa is an **independent concept project**, not client work. It is a premium B2B SaaS brand and
frontend for a fictional AI operations platform that brings workflow automation, projects, tasks,
analytics and integrations into one workspace.

I designed the brand identity, including a vector ribbon-"N" logomark and wordmark, and a dark
"midnight console" design system. I then built a high-converting marketing site and a fully
interactive dashboard demo in React and TypeScript.

Highlights:
• Cinematic hero with a live, animated product preview, plus an interactive automation run and analytics section
• Dashboard with 7 working sections: guided tour, task board with filters and status changes, automation toggles with simulated test runs, analytics period switching, a rule-based AI assistant, and a ⌘K command palette
• Responsive from 390px phones to 1440px desktops, with a mobile drawer and bottom tab bar
• Accessibility built in: WCAG 2.2 AA checks with axe, full keyboard support, reduced-motion support
• Lighthouse 96–100 on performance and 100 on accessibility, best practices and SEO; CLS 0
• 202 automated Playwright tests across desktop, tablet and mobile

All names, people, data and pricing are fictional demo content. There is no backend; demo changes are
saved only in the visitor's browser.
