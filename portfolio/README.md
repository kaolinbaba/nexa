# Nexa: portfolio package

Independent concept project (not client work). All data is fictional.

| File | What it is |
|---|---|
| `cover.png` | Portfolio cover (1600×1200), composed from real screenshots of the build |
| `case-study.md` | Short case study: brief, direction, build, quality results |
| `upwork.md` | Upwork title, description, skills and upload order |
| `tech-stack.md` | Technology list |
| `setup.md` | How to run, test and rebuild the project |
| `screenshots/` | Real screenshots of the production build (desktop / tablet / mobile, 2–3× DPR) |

Screenshots and the cover are regenerated by `node qa/portfolio.mjs` against a running
`vite preview`. See `setup.md`.
